Три сигнала

Интерфейс из бумаги и чернил. Цвет появляется, только когда сообщает о доставке, и у каждого цвета одно значение. Кнопки чернильные, поэтому сигналы не теряются среди действий.

В сети сейчас
Зелёный: человек достижим, сообщение уйдёт сразу. Больше зелёный ничего не значит.
В пути
Янтарный: сообщение ждёт, когда собеседник появится в сети. Оно не потерялось и уйдёт само.
Не отправлено
Красный: сломалось, заблокировано или не ушло. Для «важно» и для украшения не используется.

Синий используется только для кольца фокуса с клавиатуры. Шесть тонов окрашивают имена авторов в группах.

Цвет

Все значения приходят из одного файла design/system/tokens.json. Сборщик выпускает из него CSS для сайта и страниц, темы и DesignTokens.swift для iOS. Ниже значения текущей темы.

Шрифт

IBM Plex Sans для текста, Plex Sans Arabic для арабского, Plex Mono только для ID и ключей. Время, размеры и счётчики набраны Plex Sans: у него все цифры одной ширины. Китайский берётся из системного шрифта. Файлы шрифтов лежат в design/system/fonts, лицензия OFL. На телефоне роли крупнее, на iOS они растут вместе с системной настройкой размера текста.

Отступы и размеры

Отступы идут по шкале, радиус показывает уровень элемента: кнопка, поле, карточка, шторка. Каждый размер в клиентах берётся отсюда, своих чисел в разметке нет.

Обводки и тени

Тень бывает только у того, что всплывает поверх: у покоящихся элементов её нет. Числа: сдвиг по горизонтали, по вертикали, размытие.

Размеры

Движение

Быстрое и по делу: четыре длительности и одна кривая. При «Уменьшить движение» сдвиги заменяются затуханием не дольше 120 мс. Бесконечных анимаций нет: ожидание показывают слова и неподвижная точка.

Загрузка в кнопке

Текст остаётся на месте, справа появляется точка ожидания. Ошибка показывается в той же строке, а не окном.

Экспорт не удался: на устройстве не хватает места. Освободите 20 МБ и повторите.

Наложения

Тост

Только подтверждения, с «Отменить», где отмена возможна. Уходит сам, при наведении держится.

Диалог опасного действия

Последствие одной фразой, на кнопке глагол. Esc закрывает.
